ノド糊しろ白

製本の糊しろになる白を、下版PDFのノド側に後から追加します。InDesign・Illustratorに戻らずPDF単体で処理でき、元ファイルとバイト単位で一致する状態まで削除できます。

ツールを開く（別タブ）→

このツールでできること

貼り込み・展開もののノド側には、製本時に糊が付く白の帯が必要になります。このツールは、製本方法とパーツから必要な白を判定し、分割入稿された複数PDFの並び順から継ぎ目の位置を割り出して、下版PDFに白を一括で入れます。白は元PDFの末尾に追記されるだけなので、あとから削除すれば元ファイルと完全に一致するところまで戻せます。ファイルはブラウザの中だけで処理され、どこにも送信されません。

まず試すなら：testset/ の5ファイル（別丁扉・本文A・片観音展開・Z折展開・本文B）をまとめてドロップしてみてください。構成が自動で組み上がるところから継ぎ目の選択まで、ひと通りの流れを実データ無しで確認できます。

2つのタブ

判定
1問1画面。製本方法 → パーツ → ノドの印刷 → 位置、の順に答えると「内側◯mm／ドブ側◯mm」の数値が出ます。
ノドに白付加
分割入稿されたPDFをまとめて投げ込み、構成を組んで継ぎ目を決め、白を入れて書き出します。

判定タブ

  • 選択肢は数字キー 1 2 3 でも選べます。
  • 戻るボタンと Backspace で一つ前へ。上部のパンくずはクリックでその段階まで戻れます。
  • 中綴じを選んだ時点、「印刷なし」を選んだ時点で、そこから先は聞かずに終わります。
  • 表2-3だけは「背厚分＋両側2.5mm」で表紙まわりの処理なので、本文PDFへの適用対象からは外れます。

三つ折りは巻三つ折り・Z折りとも「片観音折」として同じ判定になります。必要な白の寸法は同じで、違うのは入る位置だけなので、そこは台割タブで決めます。

白を入れる（ノドに白付加）

  1. PDFをまとめて投げ込む。分かれて入稿されたファイルはまとめてドロップしてください。投げ込んだ順番がそのまま本の並び順になります。並びが違えば ▲▼ で入れ替えます。
  2. 種別を確認する。各ファイルにはファイル名と判型から種別が自動で付きます（本文／別丁扉・見返し／二つ折り・片観音・両観音）。違っていればプルダウンで直してください。総頁は本文ファイルのページ数から自動計算されるので入力不要です。
  3. 基本条件を決める。製本方法／綴じ方向／ページ掛け／継ぎ目の既定（前で貼る／後ろで貼る）。既定は「前で貼る」で、製本会社によって変わります。一度倒せば全継ぎ目に反映されます。
  4. 継ぎ目を選ぶ。右パネルの「継ぎ目」に、貼り込みになるパーツが1行ずつ並びます。行をクリックすると選択画面に切り替わり、貼る面を絵柄を見ながら選べます。
  5. 「この内容で確定」を押す。画面下に貼り付いているボタンです。展開もの（二つ折り・巻三つ折り・Z折り・両観音）は確定が必須で、押すまで書き出せません。
  6. 「白を追加して保存」で書き出す。ファイルごとに、元の名前＋_糊しろ白 で保存されます。構成とファイル割当は「構成を保存」でJSONに残せます。
三つ折りは折り方を必ず確認してください。巻三つ折りとZ折り（蛇腹）は展開PDFの見た目が同じで、ファイルからは判別できません。ファイル名に「Z折」「蛇腹」があるときだけ自動でZ折りに寄せ、無ければ巻三つ折り扱いになります。違っていれば種別プルダウンで直してください。

展開入稿のパーツ

観音や二つ折りは展開の見開きPDFで入稿されるため、頁数とPDFのページ数が一致しません。構成側でこの対応を持っています。

形状頁数PDF糊付け位置白
二つ折り4p2折スジ内1.5mm
片観音（巻三つ折り）6p2折スジ内1.5mm
片観音（Z折り）6p2展開紙の端内1.5＋ドブ3mm
両観音8p2折スジ内1.5mm

糊が付く面の数は「本の中の位置」で変わる

位置糊が付く側必要な面
本文の途中前後どちらか片側だけ1面
巻頭・巻末隣の折との継ぎ目 ＋ 見返し・表2-3の対向面2面（前後とも）

選択画面の上に、そのパーツの位置と必要な面数が表示されます。折スジの左右の面は「前で貼る側／後ろで貼る側」にあたるので、本文の途中ならそのうち1つ、巻頭・巻末なら2つとも必要になります。自動選択もこの面数に従い、途中の位置で候補が2つとも絵柄ありのときは絵柄の少ない方を採ります。必要より多く選ぶと「この位置は1面でよい」と注意が出ます（書き出しは止めません）。

巻き込み側・ノドになる端を選ぶ

  • 巻三つ折り・両観音…「左を巻き込む／右を巻き込む」を選んでから、その折スジの面を選びます。
  • 二つ折り…表裏×左右の4候補から、絵柄の少ない面を選びます。
  • Z折り（蛇腹）…本体に貼られるのは折スジではなく展開紙の左端か右端です。①ノドになる端 →②その端の外面／中面、の2段で選びます。

同じ紙の端でも、外面と中面ではPDF上の左右が入れ替わります（裏なので）。左端をノドにすると外面はPDFの左辺、中面は右辺に白が入ります。ツール側でこの反転を持っているので、面を選べばそのまま正しい辺に入ります。糊付け面のサムネイルは端の帯を拡大して表示します（展開全体の縮小では1.5mmの中身が見えないため）。

継ぎ目の行の見かた

表示意味
一択候補が1つしかないので決める必要なし
✓ 右巻き込み・外面(右)確定済み。何を選んだかがそのまま出ます
左端・外面／未確定選んではいるがまだ確定していない
巻き込み側を選ぶ／ノドになる端を選ぶまだ何も選んでいない
赤い表示実測の結果、別の候補の方が白の追加が少ない
  • 確定したあとに面や巻き込み側を触ると、また未確定に戻ります。変えたなら、もう一度確定を押してください。
  • 二択を倒し直すと、選んでいた面は解除されます。別の面になるためです。
  • ノド際の絵柄を測っているあいだは確定を押せません（測り終わると押せるようになります）。
  • 確定済みの継ぎ目は、あとから測り直しても自動選択で勝手に書き換わりません。
  • 選択の余地がない継ぎ目は自動で確定します。巻頭の別丁扉、巻末の端数などです。

貼り合わせる面の考え方

本文途中の貼り込み — 片面だけでよい

貼り込むパーツの表と裏の両面に白を作る必要はありません。糊が付くのは前後どちらか一方の面だけなので、どちらの面で貼るかはレイアウトを見て選べます。ただし、選んだ側は貼り合う相手のページも白である必要があります（白と白で貼り合わせる）。

例：ペラの表が地色ベタ・裏が全面白だとします。裏の面で貼ることにして、その次のページが白なら、どちらにも手を入れずに済みます。白を作るのは最低限に。すでに白い面があるなら、それを使うのが正解です。

見返し・表2-3に対向する場合 — 両面必要

見返しや表2-3に対向する別丁扉・ペラは、前後の両側が貼り付けられる形になります。この場合は表裏どちらにも糊が付くため、両面に絵柄があれば両面とも白が必要です。指示一覧でも、この2つは別の注意として出し分けています。

元に戻す

「白を削除して保存」を押すと元に戻ります。このツールは元PDFのバイト列を一切書き換えず、末尾に追記するだけで白を足しています。削除は追記部分を切り落とす処理なので、元ファイルとバイト単位で完全に一致します。

Acrobatで一度上書き保存された後や、RIP・面付けソフトを通過した後でも削除できます。この場合は該当部分だけを消す処理に切り替わるため完全一致にはなりませんが、白は確実に消えます。削除はレイヤー名「ノド糊しろ白」を手がかりに、フォームXObjectの中まで探して行います。レイヤー名を変えて適用した場合は、削除時にも同じ名前を指定してください。

電子書籍に流用するときは：レイヤーを非表示にするのではなく、削除したファイルを渡してください。変換ツールがレイヤーの表示状態を無視することがあります。

対応しているPDF

  • トンボ付き（TrimBoxあり）／トンボなし（TrimBoxなし）どちらも
  • 旧来の相互参照表／相互参照ストリーム＋オブジェクトストリーム（InDesign書き出しはこちら）どちらも
  • /Rotate が付いたページも、見た目の左右でノド側を判定します
対応していないもの：暗号化（パスワード付き）PDFは読み込み時に弾きます。電子署名付きPDFは追記すると署名が無効になります。面付け済み・見開きPDFは使えません（ノドが中央に来るため）。単ページ書き出しに適用してください。
また、RIP通過後のファイルには白を追加できません。TrimBoxが失われMediaBoxだけになり、用紙サイズを仕上がりとみなしてしまうためです。白の追加は必ず下版前の元データに対して行ってください（削除はRIP後でも効きます）。

フィードバックを送る

このツールは実案件の条件をまだ集めている途中です。特に分割入稿・観音・Z折りは実データでの確認がこれからなので、使ってみて気づいたことをそのまま送ってください。ヘッダー右上の フィードバック ボタン、または書き出し直後に画面下に出る誘導から送れます。

  1. 結果を3択で選ぶ。「問題なし」「結果が違う」「迷った」のいずれか。ここだけ必須です。
  2. 種別・該当ページを補う。判定ルール／構成の組み立て／継ぎ目・貼る面／展開もの／白の位置・寸法／書き出し・削除／要望、から選べます。
  3. コメントを書く。「製本部の指示と違った」「Z折りの端の選び方が分からなかった」など、短くて構いません。
  4. 送信する。お名前欄は任意ですが、入れておくと次から自動で入ります。

案件の条件（製本方法・綴じ方向・ページ掛け・総頁）、ファイル名と種別、組み上がった構成、継ぎ目でどの面を選んだか、実際に出力される白の一覧は自動で添付されます。手で書き写す必要はありません。何が送られるかは、送信画面の「一緒に送られる内容を確認する」で全文を確認できます。

PDFファイルそのものはアップロードされません。送られるのは上記のテキストと、プレビュー中の1面を縮小した画像だけです。取引先名などが出ると困る場合は、送信前に内容を確認のうえ、コメント欄で補足してください。

うまくいかないとき

「白を追加して保存」が押せない・「未確定 ◯ 件」になっている
展開もの（二つ折り・巻三つ折り・Z折り・両観音）で、貼る面の確定がまだ残っています。ボタンにカーソルを合わせると、どの継ぎ目が未確定かが出ます。該当する継ぎ目の行をクリックして面を選び、画面下の「この内容で確定」を押してください。
「この内容で確定」が押せない
ノド際の絵柄を測っている最中です。測り終わると押せるようになります。
継ぎ目の行が赤くなっている
実測の結果、別の候補の方が白の追加が少なくて済む、という表示です。エラーではありません。レイアウト上その面で貼る必要があるなら、そのままで構いません。
構成の並び順が違う
投げ込んだ順番がそのまま本の並び順になります。ファイル一覧の ▲▼ で入れ替えてください。種別（本文／別丁扉／観音など）が誤って推定されている場合も、プルダウンで直すと構成が組み直されます。
物理ページの左右が逆に見える
ノドの左右は通しページではなく物理ページの偶奇で決まります。別丁扉が巻頭に入ると以降の物理ページが2つずれるため、通しページの感覚とはずれます。構成欄で物理ページを確認してください。
ドブ側の白が入らない・警告が出る
TrimBoxが無く、かつドブも無いPDFは、ドブ側の白を入れる余地がありません（内側のみ有効）。この場合は Python版の --grow-media で用紙ごと広げてください。
Z折りなのに巻三つ折りとして扱われている
展開PDFからは自動判別できません。ファイル名に「Z折」「蛇腹」が無いと巻三つ折り扱いになります。種別プルダウンでZ折りに変更してください。入稿時に折り方を確認しておくのが確実です。
過去に書き出した観音のPDFが気になる
2026年8月22日より前のバージョンには、折スジ基準の白が紙の端に描かれる不具合がありました（二つ折り・巻三つ折り・両観音が該当。単ページの案件は影響ありません）。画面の指示一覧は正しい位置を出していたため、PDFを開かないと気づけません。該当しそうな案件は白の位置を確認してください。
